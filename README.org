#+Title: Ferris Sweep — ZMK config

Firmware-config til en Ferris Sweep (34 taster, 2x nice!nano v2), bygget
automatisk via GitHub Actions. ZMK's indbyggede shield-navn for denne
type bræt er =cradio=.

* Sådan bygges og flashes firmwaren

1. Push ændringer til dette repo (eller kør workflowet manuelt under
   "Actions" → "Build" → "Run workflow").
2. GitHub Actions bygger tre .uf2-filer og samler dem i et zip-artifact:
   - =cradio_left-nice_nano_v2-zmk.uf2=
   - =cradio_right-nice_nano_v2-zmk.uf2=
   - =settings_reset-nice_nano_v2-zmk.uf2= (nulstiller Bluetooth-parringer)
3. Download zip'en fra Actions-kørslen og pak den ud.
4. Sæt controlleren i bootloader-mode ved at dobbelt-trykke reset-knappen
   på nice!nano'en (den dukker op som et USB-drev, "NICENANO").
5. Træk den rigtige .uf2-fil ind på drevet — =_left= til venstre halvdel,
   =_right= til højre halvdel. Brættet genstarter selv efter kopiering.
6. Parring: tænd begge halvdele, de forbinder automatisk til hinanden;
   åbn Bluetooth-indstillinger på din computer/telefon og vælg tastaturet.

* Layout

Tre lag: basis, tal/matematik og symboler/navigation.

** Lag 0 — basis (hold ingen tommel)

Bogstaver i QWERTY, med home row mods på A S D F / H J K L ; (tryk = bogstav,
hold = modifier). Venstre tommel (ESC) holdes for lag 1, højre tommel
(BSPC) holdes for lag 2.

#+begin_example
Q  W  E  R  T        Y  U  I  O  P
A  S  D  F  G        H  J  K  L  ;
gui alt ctrl shift    shift ctrl alt gui
Z  X  C  V  B        N  M  ,  .  /
      ESC SPACE      ENTER BSPC
      (L1)                 (L2)
#+end_example

** Lag 1 — tal og matematik (hold venstre tommel)

#+begin_example
1  2  3  4  5        6  7  8  9  0
!  @  #  $  %        ^  &  *  (  )
-  _  =  +  /        \  |  ~  ,  .
#+end_example

]  <  >  '  "        ←   ↓   ↑   →   DEL
`  :  _  \  ?        HOME PGDN PGUP END TAB
#+end_example

* Justering

- Home row mod-timing (=tapping-term-ms=, =flavor=) står i
  =config/cradio.keymap= i =behaviors { hm: ... }=. Føles mods for
  "kliklette" eller for langsomme, er det her man skruer.
- Strømstyring (søvn, batteri-rapportering) og ZMK Studio-indstillinger
  står i =config/cradio.conf=.
- Board/shield-kombinationer til GitHub Actions-matricen står i
  =build.yaml=.

* Lokal udvikling

Mapperne =zephyr/=, =zmk/=, =modules/=, =build/= og =.west/= er et lokalt
west-workspace (fra =west init= / =west update=) og er ikke en del af
selve configen — de er i =.gitignore=, fordi GitHub Actions henter sin
egen kopi ved hver build.
